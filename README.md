# San Telmo — Descubre tu maridaje

Microapp conceptual de maridaje para Vinería San Telmo, Sevilla. Demo independiente, no afiliada ni aprobada por el restaurante.

## Desarrollo local

```powershell
npm install
npm run dev
```

## Compilación

```powershell
npm run build
npm run preview
```

Las sugerencias son ejemplos de estilo, no referencias de vinos reales. No muestran precios, disponibilidad, ingredientes ni alérgenos. Consulta la carta vigente en https://restaurante.covermanager.com/wp-content/uploads/2025/08/2.pdf.
